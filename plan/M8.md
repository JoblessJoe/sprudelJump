# Milestone M8 — Monsters (stomp-kill and lethal contact)

Spec: `plan/CORE_SPEC.md` — read "Monster representation" and "Monster
spawning" now. Skip "Bullets and firing" — that's M9, not this milestone.
Assumes M7 (breakable platforms, 17-float state) is already done.

No shooting yet in this milestone. `action` is still a single float (steering
only) — monsters can kill you or be stomped without needing a shoot output at
all. Don't touch the `action` type in this milestone; that change belongs to
M9.

## What to build in `env.py`

1. `self.monsters = []` added to `reset()`.
2. When spawning a new platform (already happening per M4/M7), also roll for a
   monster on it per `CORE_SPEC.md`'s "Monster spawning" formula.
3. Collision, per `CORE_SPEC.md`'s updated `step()` order: while falling
   (`velY > 0`), a feet-cross-top test against each monster (same shape as the
   platform test, using `MONSTER_WIDTH`/`MONSTER_HEIGHT`) is a stomp — kill the
   monster (remove it, `self.totalHeight += MONSTER_KILL_BONUS`), bounce
   (`BOUNCE_VELOCITY`). Any other overlap with a living monster (not a stomp)
   is fatal: `done = True`.
4. Housekeeping: remove monsters with `y > SCREEN_HEIGHT`, shift monster `y` on
   scroll, same as platforms.
5. State vector grows from 17 → 23 floats: append the 3 nearest monsters above
   the player, 2 floats each (relative x, relative y), padding `[0.0, 1.0]` per
   missing one. Per `CORE_SPEC.md`'s full ordering, this comes after the 5
   platform slots.

## Self-checks

- **Stomp**: place a monster directly above a platform the player will land on
  from above. Run until it happens. Confirm the monster is removed and
  `self.totalHeight` jumped by `MONSTER_KILL_BONUS` at that step, and the
  player bounced (did not die).
- **Lethal contact**: place a monster overlapping the player's x-range at the
  player's current y, with `player.velY <= 0` (so the stomp branch can't
  fire — e.g. right after a bounce, while still rising). Confirm `done`
  becomes `True` and the monster is untouched (not removed).
- `len(env.reset())` == 23.
- Run 5000 steps, `action = 0.5`, fixed seed. Count monsters spawned in the
  first 1500 vs. last 1500 steps — later count should be visibly higher.
