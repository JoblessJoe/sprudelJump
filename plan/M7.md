# Milestone M7 — Monsters, shooting, and breakable platforms

Spec: `plan/CORE_SPEC.md` (already updated for this milestone — read it in full
again now, even if you read an earlier version before; the interface, state
vector, and constants all changed: `action` is now `[steer, shoot]` not one
float, state is 23 floats not 12, and there are new sections: Monster
representation, Monster spawning, Bullets and firing, Breakable platforms).

This extends the already-working M1-M6 env, it doesn't replace it. Build on
top of the existing physics/scrolling/difficulty logic — don't rewrite it.

## What to build in `env.py`

1. `self.monsters`, `self.bullets`, `self.cooldown` added to `reset()`.
2. Platforms become `(x, y, width, breakable)` 4-tuples (was 3). Update every
   place that constructs or reads a platform.
3. Monster stomp/contact, firing, bullet movement/collision, breakable-platform
   removal — all per the updated `step()` order in `CORE_SPEC.md` (steps 4-9).
4. `_getState()` grows to 23 floats: player (2) + 5 platforms x 3 floats
   (x, y, breakable) + 3 monsters x 2 floats (x, y).

## Self-checks — run all of these, fix anything that fails before moving on

- **Stomp kill**: place one monster directly above a platform the player will
  land on from above. Run enough steps for the player to fall onto it. Confirm
  the monster is removed from `self.monsters` and `self.totalHeight` jumped by
  at least `MONSTER_KILL_BONUS` at that step, and the player bounced (did not
  die).
- **Lethal contact**: place a monster directly in the player's horizontal path
  at the player's *current* height (not one it would stomp onto — e.g. same y,
  overlapping x, with `player.velY <= 0` so the stomp branch can't fire).
  Confirm `done` becomes `True` and the monster is NOT removed (it wasn't shot
  or stomped, just walked/fallen into).
- **Bullet kill**: place a monster directly above the player, well within
  `BULLET_SPEED` reach within a few frames. Step with `action = [0.5, 1.0]`
  repeatedly. Confirm a bullet appears in `self.bullets`, travels upward, the
  monster is removed on contact, and `self.totalHeight` jumped by
  `MONSTER_KILL_BONUS`.
- **Cooldown**: step with `action = [0.5, 1.0]` every frame for
  `BULLET_COOLDOWN_FRAMES * 3` frames. Print `len(self.bullets)` created total
  (track a counter, since old bullets despawn) — confirm it's roughly
  `3`, not `BULLET_COOLDOWN_FRAMES * 3` (i.e. cooldown is actually limiting
  fire rate, not firing every frame).
- **Breakable platforms**: force-spawn a platform with `breakable=True` under
  the player, run steps until the player bounces on it, confirm it's removed
  from `self.platforms` right after (a normal, non-breakable platform placed
  the same way must NOT be removed after the same bounce — test both in the
  same script for a direct comparison).
- **Difficulty ramp sanity** (extends M4's check): run 5000 steps with
  `action = [0.5, 0.0]`, seed fixed. Print how many monsters and how many
  breakable platforms were spawned in the first 1500 steps vs. the last 1500 —
  both counts should be visibly higher later in the run (difficulty scaling
  applies to spawn chances too, not just gap/width).
