# Milestone M7 — Breakable platforms

Spec: `plan/CORE_SPEC.md` — read the "Platform representation" and "Breakable
platforms" sections specifically (already updated for this). Skip the Monster
and Bullets sections for now — those are M8/M9, not this milestone.

This extends the already-working M1-M6 env. Build on top of the existing
physics/scrolling/difficulty logic — don't rewrite it.

## What to build in `env.py`

1. Platforms become `(x, y, width, breakable)` 4-tuples (was 3). Update every
   place that constructs or reads a platform.
2. When spawning a new platform, roll `breakable` per the formula in
   `CORE_SPEC.md`'s "Breakable platforms" section (difficulty-scaled chance).
3. Initial platforms from `reset()` are always `breakable=False`.
4. Collision: after applying a bounce off a platform where `breakable=True`,
   remove that platform from `self.platforms` right after.
5. State vector grows from 12 → 17 floats: each of the 5 platform slots gets a
   3rd float (the breakable flag, `1.0`/`0.0`), per `CORE_SPEC.md`. Do NOT add
   monster floats yet — that's M8. Padding for a missing platform slot is now
   `[0.0, 1.0, 0.0]` (3 values), not `[0.0, 1.0]`.

## Self-checks

- Force-spawn one `breakable=True` platform and one `breakable=False` platform
  at the same height in different x positions the player will bounce on. Run
  until both bounces happen. Confirm the breakable one is removed from
  `self.platforms` right after its bounce, and the normal one is still there.
- `len(env.reset())` == 17.
- Run 5000 steps, `action = 0.5`, fixed seed. Count breakable platforms spawned
  in the first 1500 steps vs. the last 1500 — the later count should be
  visibly higher (difficulty scaling applies to spawn chance, not just
  gap/width).
