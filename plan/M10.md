# Milestone M10 — Update demo_render.py for monsters, bullets, breakable platforms

Spec: `plan/CORE_SPEC.md`. Assumes M7-M9 are all done (`env.py` now has
monsters, bullets, breakable platforms, and a 2-element `action`).

`demo_render.py` already exists from M6 and currently only draws the player
and normal platforms with a single steering key. Extend it, don't rewrite it
from scratch.

## What to change

1. `env.step(...)` call site: build `action = [steerValue, shootValue]`
   instead of a bare float.
2. Add a shoot control: Space bar held down → `shootValue = 1.0` this frame,
   else `0.0`. Steering (arrows/A/D) is unchanged, just becomes `action[0]`.
3. Draw monsters as a distinct shape/color from platforms and the player.
4. Draw bullets as small thin rectangles.
5. Draw breakable platforms in a visibly different color/tint from normal
   platforms, so it's obvious at a glance which is which.

Keep it under ~130 lines total. This is still just a human sanity-check tool,
not used for training — don't add anything beyond what's listed here.
