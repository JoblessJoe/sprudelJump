# Milestone M9 — Shooting and bullets

Spec: `plan/CORE_SPEC.md` — read "Bullets and firing" now. Assumes M7
(breakable platforms) and M8 (monsters, 23-float state) are already done.

**This is the milestone that changes the `action` interface** from a single
float to a 2-element list `[steer, shoot]` — per `CORE_SPEC.md`'s `step()`
docstring. This touches every existing caller of `env.step()`, including your
own old self-check scripts from M1-M6/M7/M8. Update `check_m*.py` (all of
them) to pass `[steerValue, shootValue]` instead of a bare float, and re-run
each one to confirm nothing else broke before writing any new code for this
milestone. Do this first, as its own small step, before adding bullets.

## What to build in `env.py`, after the interface update above

1. `self.bullets = []`, `self.cooldown = 0` added to `reset()`.
2. `horizontalVelocity` now reads `action[0]` instead of `action`.
3. Firing: if `action[1] > 0.5` and `self.cooldown == 0`, spawn a bullet at
   `[player.x + PLAYER_WIDTH/2 - BULLET_WIDTH/2, player.y]`, reset
   `self.cooldown = BULLET_COOLDOWN_FRAMES`. Decrement `self.cooldown` by 1
   (floor 0) every step regardless.
4. Every step: move each bullet up by `BULLET_SPEED`, remove any with
   `y < -BULLET_HEIGHT`. Check each remaining bullet against each living
   monster — on overlap, remove both, `self.totalHeight += MONSTER_KILL_BONUS`.
5. Bullets shift `y += scrollAmount` on scroll, same as platforms/monsters.

State vector is unchanged in this milestone (still 23 floats) — bullets are
deliberately not part of state, per `CORE_SPEC.md`.

## Self-checks

- After updating the old scripts: re-run `check_m2.py` through whichever of
  your M7/M8 self-check scripts exist. All must still pass with the new
  `[steer, shoot]` action format before you write any bullet code.
- **Bullet kill**: place a monster directly above the player, within a few
  frames of `BULLET_SPEED` reach. Step with `action = [0.5, 1.0]` repeatedly.
  Confirm a bullet appears, moves upward, the monster is removed on contact,
  and `self.totalHeight` jumped by `MONSTER_KILL_BONUS`.
- **Cooldown**: step with `action = [0.5, 1.0]` every frame for
  `BULLET_COOLDOWN_FRAMES * 3` frames. Track total bullets ever created (a
  counter, since old ones despawn) — confirm it's roughly `3`, not
  `BULLET_COOLDOWN_FRAMES * 3` (cooldown is actually limiting fire rate).
